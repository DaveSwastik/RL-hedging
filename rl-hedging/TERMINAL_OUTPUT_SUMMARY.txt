## 🔍 Displayed Metrics (Every 10%)

At **500 update intervals** (for 5000 total):

| Metric | Computed From | What It Means |
|--------|---------------|--------------|
| Actor Loss | Policy gradient loss | How well policy improves (should ↓) |
| Value Loss | MSE(predicted, actual) | How well value estimates (should ↓) |
| GPD Loss | Tail risk modeling | How well tail distribution learned (should > 0) |
| Tail Events | Count of samples < u | How many tail risk events seen so far |

## 🎮 If You Need Verbose Debug Output

Edit `run_training.py` and add one line:

```python
trainer = A2CTrainer(...)
trainer.verbose = True  # ← Add this line

train_loop(trainer, ...)
```

Now you'll see all the detailed debug output again.

---

## 📝 Code Changes Made

1. **Added import**: `from tqdm import tqdm`
2. **Added `verbose` flag** to `A2CTrainer.__init__()`
3. **Wrapped training loop** with `tqdm(total=total_updates)`
4. **Accumulate metrics** every 10% of training
5. **Display postfix** with metrics every 10%
6. **Silenced debug prints** (only show if `trainer.verbose = True`)
7. **Added nice summary box** at end with training stats
